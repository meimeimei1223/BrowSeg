BrowSeg benchmark

Server mode (used for the paper's measurements): serve with node serve.mjs 8080 --bench <cases dir> and open bench.html?tag=<name>. Results are written to paper_jiim/paper_benchmarks/data/browser/<tag>/.
Local mode (reproduce the paper from the public URL): open bench.html?local=1, choose the folder that holds the cases (one sub-folder per case, e.g. ircad01/ … ircad20/ with the DICOM files of 3D-IRCADb-01), press Run. The label-map hashes are compared with the paper's records and the results can be downloaded as one JSON file. Nothing is uploaded; the CT stays on this computer.

Parameters: tag (server mode: output folder, required), cases (comma list, default all), tasks (e.g. total:liver;total:-;liver_segments:-;liver_vessels:-), reps (default 3), cold=1 (clear the weight cache first), plus the engine parameters cpu=1, fp16=1, order=1|3, threads=N, gpuchunk=N (WebGPU: at most N compute steps per GPU submission, waiting for each unless gpuchunkwait=0; 0 = whole network at once, as in the paper).
